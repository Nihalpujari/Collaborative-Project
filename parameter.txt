COHERENCE (do the 3 outputs match each other?)
  ImageBind encodes all 3 → same vector space
  s1 = sim(text  ↔ image)
  s2 = sim(text  ↔ audio)
  s3 = sim(image ↔ audio)
  TSAS      = (s1 + s2 + s3) / 3
  Coherence = TSAS - λ × variance(s1, s2, s3)

Score = TSAS - penalty

If everything is consistent → variance = 0 → Score = TSAS (no change)
If one modality is off → variance high → Score drops below TSAS


Image → Vector

An image is just a grid of pixels. Each pixel has 3 numbers (R, G, B).

224×224 image = 224 × 224 × 3 = 150,528 numbers
But that's too raw. ImageBind uses Vision Transformer (ViT):

Step 1 — Cut image into patches
  224×224 → 196 patches of 16×16 pixels each
  (like cutting a photo into a 14×14 grid of small squares)
Step 2 — Each patch → small vector
  16×16×3 pixels → linear layer → 768 numbers
Step 3 — Patches talk to each other (attention)
  patch of eye influences patch of glasses
  context across the whole image
Step 4 — Linear projection head
  → single vector of 1024 numbers


Audio → Vector

Audio is a waveform — just a list of pressure values over time. Too raw to compare directly.

Step 1 — Convert waveform to Spectrogram
  Raw waveform → 2D heatmap
  x-axis = time
  y-axis = frequency (128 mel bins)
  color  = loudness
  Now audio LOOKS like an image
Step 2 — Treat spectrogram exactly like an image
  Apply ViT with patch size 16, stride 10
  Same transformer logic as image encoder
Step 3 — Linear projection head
  → single vector of 1024 numbers
  
The key insight:

ImageBind converts audio into a spectrogram first — turning a sound into a 2D picture. Then it processes it exactly like an image. That's why the same ViT architecture works for both.

image   → ViT → 1024-dim vector
audio   → spectrogram → ViT → 1024-dim vector
text    → transformer → 1024-dim vector
All same size → cosine similarity works

Step 1 — convert each metric to a 0–1 grade using FIXED external goalposts
         MOS 1–5 (ITU standard) , Aesthetic 1–10 (LAION scale)
         WER 0–1 , BERTScore 0–1
         CLIP floor = mismatched-pair baseline 

Step 2 — combine WITHIN each modality
         Text  = BERTScore
         Image = √(CLIP × Aesthetic)
         Audio = √(MOS × WER_grade)

Step 3 — combine ACROSS modalities, equal weight each
         Final = (Text × Image × Audio)^(1/3)

1 Prompt → 3 Generated Outputs
           ├── Text  (generated paragraph)
           ├── Image (generated picture)
           └── Audio (generated speech)


Q_text  = BERTScore(generated_text, prompt)

Q_image = avg(CLIP_score, Aesthetic_score)
          - λ × variance(CLIP_score, Aesthetic_score)

Q_audio = avg(CLAP_score, 1 - WER)
          - λ × variance(CLAP_score, 1 - WER)



LLM Judge rates all 56 prompt outputs → overall score per prompt
          ↓
Linear Regression on [Q_text, Q_image, Q_audio] → overall                                           X (features) = [Q_text, Q_image, Q_audio]   ← 3 columns
          ↓                                                                                         y (target)   = LLM overall score             ← 1 column
Learned weights: w1, w2, w3


s1_weighted = s1 × (w1×Q_text  + w2×Q_image) / (w1 + w2)
s2_weighted = s2 × (w1×Q_text  + w3×Q_audio) / (w1 + w3)
s3_weighted = s3 × (w2×Q_image + w3×Q_audio) / (w2 + w3)


WTSAS = (s1_weighted + s2_weighted + s3_weighted) / 3

Final Score = WTSAS - λ × variance(s1_weighted, s2_weighted, s3_weighted)
